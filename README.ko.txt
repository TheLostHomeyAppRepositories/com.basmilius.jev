Jev는 집 안 상황에 따라 Homey Flow가 결정을 내리도록 돕습니다. 어울리는 조명 장면을 고르거나, 알림을 나중에 보내도 되는지 판단하거나, 추가 조명이 얼마나 필요한지 평가할 수 있습니다.

텍스트와 Flow 태그로 상황을 직접 설명합니다. Jev는 제공한 맥락만 사용합니다. 앱이 기기를 읽거나 집 전체의 상태를 수집하지 않습니다.

네 가지 실행 카드:
- 예/아니요 질문으로 불리언 답변과 예일 확률을 받습니다.
- 한 줄에 하나씩 입력한 2–255개 답변 목록에서 선택합니다.
- 직접 설명한 세 단계로 상황을 평가합니다. 점수는 소수를 포함해 0–2입니다.
- 구조화된 상태와 질문에는 고급 JSON 카드를 사용합니다.

Advanced Flow에서 결과 태그로 다음 동작을 결정하세요. 기본 카드에는 조절 가능한 기준값이 있습니다. 답변이 불확실하면 오류 경로로 진행하므로 대체 동작을 연결할 수 있습니다.

요구 사항:
- 버전 12.4 이상의 로컬 Homey.
- API 키와 크레딧이 있는 TypeSafe 계정.
- 인터넷 연결. 제공한 맥락과 질문은 평가를 위해 TypeSafe로 전송됩니다.
- 결과 태그를 다른 카드에 연결하려면 Advanced Flow가 필요합니다.

앱 설정에 API 키를 추가하세요. 질문과 답변은 Flow 카드에서 직접 설정합니다.
