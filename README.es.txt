Jev ayuda a tus Homey Flows a tomar decisiones según la situación en casa. Elige una escena de iluminación, decide si una notificación puede esperar o evalúa cuánta luz adicional hace falta.

Tú describes la situación con texto y etiquetas Flow. Jev solo usa el contexto que proporcionas. La app no consulta tus dispositivos ni crea un inventario de tu hogar.

Cuatro tarjetas de acción:
- Haz una pregunta de sí/no y recibe una respuesta booleana y la probabilidad de sí.
- Elige de una lista de 2 a 255 respuestas, una por línea.
- Evalúa una situación con tres niveles que tú describes. La puntuación va de 0 a 2, con decimales.
- Usa la tarjeta JSON avanzada para estados y preguntas estructurados.

Usa las etiquetas de resultado en Advanced Flow para determinar las siguientes acciones. Las tarjetas simples tienen un umbral ajustable. Ante la incertidumbre, siguen la ruta de error, donde puedes conectar una alternativa.

Requisitos:
- Un Homey local con la versión 12.4 o posterior.
- Una cuenta de TypeSafe con clave API y crédito.
- Acceso a Internet. El contexto y las preguntas que proporcionas se envían a TypeSafe para evaluarlos.
- Advanced Flow para conectar etiquetas de resultado con otras tarjetas.

Añade tu clave API en los ajustes de la app. Configura las preguntas y las respuestas directamente en las tarjetas Flow.
